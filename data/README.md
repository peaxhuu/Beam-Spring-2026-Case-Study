# Data

This folder intentionally does not contain the competition dataset.

To run the analysis locally, place the workbook here as:

```
data/case_competition_data.xlsx
```

with two sheets:
- `Utilization Data` — columns for service month, payment month, and paid amount
- `Premium Data` — columns for month and premium

Check your competition's rules before sharing the raw dataset anywhere
public — most case competitions restrict redistribution even after
judging ends.
