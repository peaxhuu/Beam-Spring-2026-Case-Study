# Dental Insurance IBNP Reserving — Case Study

Actuarial case competition project estimating incurred-but-not-paid (IBNP) 
claims for a dental insurer. Finalist, BEAM Case Study Competition (March 2026).

## My Contribution
Led the **Projected Paid Lag method** implementation. Collaborated on 
Completion Factor and Bornhuetter-Ferguson approaches as team methods 
for comparison.

## Approach
- Estimated a prior expected loss ratio (ELR) of ~72%
- Recommended Bornhuetter-Ferguson given rapid premium growth, which makes 
  pure loss-development methods less reliable
- Compared reserve estimates across all three methods
